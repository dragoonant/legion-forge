# Legion Forge prompt pack (hand-run)

Generated by `tools/art/prompt_pack.py` from `docs/spec/30-figures.md`; regenerate after spec edits. Gate every image against spec 6.3 before it goes to Hunyuan3D.

## How to run
1. **Gemini, one chat per faction.** First message: attach the on-style proportion reference (`figure-style-reference.jpg` from Mallet 42k `docs/`) and paste the faction's **base** prompt (`stormtrooper` for Empire, `rebel-trooper` for Rebels). Regenerate until it passes the gate.
2. Every other figure in that chat: paste the **Edit** line plus the full prompt, so the style never drifts. If Gemini returns text only, resend once; then reword the gear.
3. Save each image as `art/unit-concepts/<slug>.png` and log it in `art/unit-concepts/PROMPTS.md`.
4. **Hunyuan3D** takes the approved PNG, no text prompt: cutout, shape, paint, finalize (`--nocut darth-vader`). No style reference image.
5. **Flux klein** for the four table mats (prompts at the end).

Order: T1, T2, T3, then terrain, tokens, mats. Empire first in each tier.
