## Goal 1: the current edition

- **There is no numbered edition.** AMG's document is the *Core Rule Book*. It carries an effective date (currently **17 June 2026**) instead of a version number. Retailers and players call the 2024-25 ruleset "2.6" or "the new edition", but AMG prints neither name on the document.
- **History we could confirm:**
  - FFG published the Learn to Play and a Rules Reference Guide (RRG, 2.x versions up to about 2021; the press mentions an RRG 2.0.2 from October 2021).
  - On **2023-01-16** AMG merged them into the first Core Rulebook, which added Passing, the panic rework, silhouettes for line of sight, and a new movement and climbing system (source 19).
  - In **July 2024** AMG previewed a large update, and the full release came at Ministravaganza 2024. It brought 1000 points, 5 rounds, rolled cover, entry from the table edge and new Battle Cards (sources 18 and 22).
  - In **April 2025** AMG published the finished new-edition rules and new print-and-play cards for every army (source 17).
  - Since then AMG has issued an update roughly every six months: Nov 2025, Apr 2026 and a Core Rule Book revision on 17 Jun 2026 (sources 14, 15 and 2).
- **Current documents:**
  - Core Rule Book, effective 2026-06-17 (source 2).
  - Battle Forces, 2026-06-17 (source 3).
  - Errata Reference, 2026-06-17 (source 4).
  - Updated Battle Cards (source 5).
  - Recon Rules, 2025-04-30 (source 7).
  - Galactic Conquest Event rules (source 8).
- **Points:** AMG publishes no separate points document. Points are printed on the per-faction print-and-play Unit and Upgrade card PDFs (April 2026, plus a Separatist and Mercenary update on 2026-05-01). Each change is explained in the six-monthly Transmissions (sources 14 to 16). The rulebook itself points readers to the docs page for current points.
- **FAQ:** AMG publishes no FAQ document. Rules questions go to the AMG forum (https://forums.atomicmassgames.com/forum/165-star-wars-legion-rules-questions/), which we did not read. Errata lives only in source 4.
- **Watch item:** the update cycle runs April and November. By that pattern the **next update is due about November 2026**, and the AdeptiCon 2026 roadmap also promised a balance update. No autumn-2026 article was listed on 2026-10-29.

## Goal 3: starter content, army size, table

- **There is no two-player core set any more.** The entry products are four single-faction **Starter Sets**, released autumn 2025 at $94.99 each. Each holds a **600-point Recon-level** army, a full set of dice (4 of each colour), movement and range tools, tokens and 24 Battle Cards (sources 13 and 24).
- **Galactic Empire Starter Set (SWQ02):**
  - Darth Vader (Commander), 2 Stormtrooper units of 11 models each, and 2 Scout Trooper units of 7 models each. That makes 37 models on 27 mm bases.
  - 7 Unit cards, 15 Upgrade cards, 10 Command cards and 24 Battle cards.
- **Rebel Alliance Starter Set (SWQ01):**
  - Luke Skywalker (Commander), 2 Rebel Trooper units of 11 models each, 1 Rebel Commando unit of 7 and 1 Wookiee Warrior unit of 6. That makes 36 models.
  - 7 Unit cards, 10 Command cards and 24 Battle cards. The upgrade count disagrees between sources: the AMG page says 15 Upgrade cards and ICv2 says 16.
- **Base costs from Legion HQ (current data, not counting upgrades):**

  | Unit | Points |
  |---|---|
  | Darth Vader, Dark Lord of the Sith | 170 |
  | Stormtroopers | 42 |
  | Scout Troopers | 48 |
  | Luke Skywalker, Hero of the Rebellion | 120 |
  | Rebel Troopers | 40 |
  | Rebel Commandos | 42 |
  | Wookiee Warriors | 62 |

  The exact subtitle printed on each starter unit card is not confirmed.
- **Standard game:**
  - Army size: at most **1000 points**.
  - Ranks: Commander 1-2, Operative 0-2, Corps 3-6, Special Forces 0-3, Support 0-3, Heavy 0-2.
  - Table: **6'x3' (72"x36")**.
  - Game length: 5 rounds.
  - Command hand: 7 cards (two each of 1, 2 and 3 pips, plus the 4-pip Standing Orders).
  - Battle Deck: 3 Objective, 3 Secondary Objective and 3 Advantage cards, plus the 3 Map Cards that pair with the objectives.
  - Battle Forces swap in their own unit lists and rank rules (source 3). Mercenaries count toward rank maximums but not minimums.
- **Recon game:**
  - Army size: at most 600 points.
  - Ranks: Commander exactly 1, Operative 0-1, Corps 2-4, Special Forces 0-2, Support 0-2, Heavy 0-1.
  - Table: 3'x3'.
  - Battle cards: one fixed Recon battle deck, and the mission is drawn at random.
  - Blue player: one player rolls a red defence die to decide.

## Goal 6: machine-readable unit data

- **Best current source: the Legion HQ 2 live bundle** (source 25). Cards are embedded as JSON; `docs/sources/legionhq2-cards-extracted-2026-10-29.json` holds **909 cards**:
  - 181 units, the upgrades and counterparts;
  - 241 command cards;
  - 43 battle cards (13 primary, 13 secondary, 17 advantage).
  - Each unit record has `rank`, `faction`, `cost`, `keywords` (with values), `upgradeBar`, `stats` (`minicount`, `hp`, `defense`, `courage`, `speed`, `hitsurge`, `defsurge`), `weapons` (`range`, `dice` r/b/w, weapon keywords) and a dated `history` of points changes.
  - **Points are current:** it includes the April 2026 changes (Wookiee Warriors 62, Rebel Commandos 42) and the 2026 Mandalorian battle force, and its latest entry is dated 2026-06-19.
  - Its source repository is not public. The open repo `Electrynth/legion-hq-web` is archived with FFG-era data, and `TravisSClark/legion-hq-api` could not be read from this session because GitHub access is limited to `dragoonant/legion-forge`.
  - Treat every value as **Fan-source**. Check each army we mark playable against the AMG card PDFs, which are image only, so the check has to be done by eye.
- AMG's card PDFs have no text layer, so a machine cannot read them. The Core Rule Book has a full text layer, and its keyword glossary (pp. 46-61) can be parsed for keyword definitions. We must reword those definitions; never paste them.

## Not found (searched 2026-10-28/29, found none; each is a finding)

- **A version number** on the current Core Rule Book. Only the effective date is printed.
- **An official FAQ document** for current Legion.
- **A standalone points document** (the FFG-era "Points Update" PDF no longer exists in that form).
- **A new two-player core set** (Empire vs Rebels) from AMG after the 2018 FFG Core Set. The faction starter sets replaced it.
- **The exact upgrade and command cards in each starter set.** Only the counts are published, and even those disagree: 15 or 16 Rebel upgrades.
- **Dice face counts in any AMG document.** The rulebook pictures each die but does not list its faces.
- **Exact lengths of the Speed-1/2/3 movement tools** in the rulebook text. The rulebook gives range segments only (6" segments plus a 3" half-range tool).
- **A Rules Reference or rules update from autumn 2026** (expected around November 2026).
- **A public GitHub repository for the current Legion HQ 2 source.** Tabletop Admiral and legion.takras.net were not examined because the Legion HQ data was enough.
