# Legion Forge

A 3D browser version of the Star Wars: Legion miniatures game, played against an AI opponent (Recon format, Galactic Empire vs Rebel Alliance starter armies).

**Play:** https://dragoonant.github.io/legion-forge/ (desktop or phone; `?seats=bot,bot` watches two AIs).

Run locally: `npm install`, then `npm run dev`. State of the project: [STATUS.md](STATUS.md); decisions: [PLAN.md](PLAN.md).
